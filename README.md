# Student Placement Tracking System (SPTS)

A web-based application developed to manage and track student placement activities efficiently. The system helps administrators manage student records, company details, placement drives, and placement status in a centralized platform.

---

## 🚀 Features

- Student Registration & Login
- Admin Dashboard
- Add / Update / Delete Student Records
- Company Management
- Placement Status Tracking
- Search Students
- Secure Authentication
- Responsive UI using Bootstrap

---
